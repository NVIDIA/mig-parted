# AGENTS.md

Guidance for AI coding agents working in this repository. See [CONTRIBUTING.md](CONTRIBUTING.md)
for the full contribution policy.

## Contribution process

- External contributors must have an `accepted` issue assigned to them before opening a pull request.
  Follow the contribution workflow in `CONTRIBUTING.md` before beginning implementation.
- Issue or PR descriptions drafted with AI must be thoroughly reviewed and verified by the user
  before they are submitted.
- Replies to maintainers in review comments or issue discussions may not be AI generated.
- All commits must be signed off for DCO using `git commit -s`. Use the configured git user's
  identity and never fabricate a sign-off identity.
- Do not open, push to, or comment on GitHub issues or pull requests without explicit user
  confirmation.
- Keep pull request titles short and imperative, and fill in `.github/PULL_REQUEST_TEMPLATE.md`.
- Keep changes minimal and scoped to the task.
